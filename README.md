# DS FITNESS

Premium public gym website + CORENERGY-style admin management panel.

## Existing Supabase setup
The original DS FITNESS schema remains intact. If the original schema has already been run, run `supabase/migrations/20260920_admin_upgrade.sql` once in Supabase SQL Editor.

## Local
```bash
npm install
npm run dev
```

Admin: `/admin/login`

The official DS FITNESS hero logo is a fixed asset in `public/ds-fitness-logo.webp`; it is not editable from the admin panel.
